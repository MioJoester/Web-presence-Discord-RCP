Companion Desktop Application

Discord Activity Sync requires a separate companion desktop application to function properly.

The companion desktop application runs locally on the user's machine and communicates with the Discord desktop client through Discord’s Rich Presence IPC interface.

Modern web browsers cannot directly establish Discord RPC connections. The companion application acts as a local bridge between Firefox and Discord.

By using the extension, you acknowledge and accept that localhost communication between the extension and the companion desktop application is required for functionality.

The companion desktop application only accepts localhost connections and is not intended for remote or public network access.
