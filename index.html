Discord Activity Sync

Shows your current Firefox tab as a Discord Rich Presence activity. Everything runs locally on your device — no external servers, cloud infrastructure, analytics, or telemetry.

How it works

01
Extension watches your active tab
The extension reads the title and URL of your currently active Firefox tab, including real-time title updates on modern single-page applications.
02
Sent to Companion Desktop App
The extension securely sends tab metadata as a local JSON payload to a lightweight companion desktop application running on localhost:3031.
03
Displayed on Discord
The companion desktop app communicates with the Discord desktop client through Discord’s local Rich Presence IPC interface.

Why a desktop app is required

Modern browsers cannot directly establish Discord Rich Presence RPC connections because Discord exposes its RPC interface only to local desktop applications.

To make Rich Presence possible, Discord Activity Sync uses a lightweight companion desktop application that acts as a secure local bridge between Firefox and the Discord desktop client.

The extension alone will not function without the companion desktop application.
